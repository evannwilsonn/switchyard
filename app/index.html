The three products

Each product keeps its own repository, dbt project and Snowflake database. Switchyard clones them, runs them, and logs what happened.

How a run works

  1. ExtractThe product's own extract scripts, with a SHA-256 manifest of every file. Clip Curator loads its saved YOLOv8 + CLIP results unless the run asks to re-run the models.
  2. Load rawRaw files land unchanged in the product's local DuckDB.
  3. Snowflake loadRaw tables go to the product's Snowflake database as Parquet, through a stage and COPY, with row counts checked against DuckDB.
  4. dbt buildEvery model and test, on Snowflake.
  5. ExportThe modeled layers are mirrored back so each dashboard is written from what Snowflake built.
